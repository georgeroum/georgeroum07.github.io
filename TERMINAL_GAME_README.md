# Brainrot World Cup (Terminal Edition)

This is a standalone terminal-playable simulation of the Roblox concept.

## Run

```bash
./run_brainrot_terminal.sh
```

or:

```bash
lua brainrot_world_cup_terminal.lua
```

## Quick Start

Inside the game prompt:

```text
status
go conveyor
conveyor
buy 2
wait 6
go enemy 2
base 2
steal 1
wait 7
go home
drop
status
```

Use `help` any time for the full command list.
